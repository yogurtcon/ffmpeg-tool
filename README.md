# FFmpeg 测试素材生成工具

用浏览器生成测试音视频：可以不传文件直接合成，也可以上传本地音视频再转格式 / 改规格。

本机需要已安装 `ffmpeg`、`ffprobe`，并能在命令行直接调用。

## 启动

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

浏览器打开 https://127.0.0.1:8765 或 https://localhost:8765。首次会用自签名证书，浏览器提示不安全时选「继续访问」。

后台跑、不要日志：

```bash
nohup python3 app.py > /dev/null 2>&1 &
```

停掉：

```bash
pkill -f "python3 app.py"
```

## 怎么用

1. **输入源**：选「无输入」由工具自己生成音/画；或选「本地上传」选一个音视频文件（可设重复次数，按整段循环拼接）。
2. **目标类型**：视频或音频。
3. **规格**：视频可选分辨率、封装（`.mp4` / `.mov`）、横竖屏、时长；音频可选 MP3 / AAC / FLAC / m4a / wav 和时长。
4. 点「生成测试文件」，完成后点下载。

生成文件在项目目录 `generated/` 下，大约 **30 分钟**后自动删除，请及时下载。
