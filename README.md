# FFmpeg 测试素材生成工具

用浏览器生成测试音视频：可以不传文件直接合成，也可以上传本地音视频再转格式 / 改规格。

本机需要已安装 `ffmpeg`、`ffprobe`，并能在命令行直接调用。

## 启动

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

浏览器打开 http://127.0.0.1:8765 或 http://localhost:8765。局域网其他机器访问 `http://目标机器IP:8765`。

后台跑、不要日志：

```bash
nohup python3 app.py > /dev/null 2>&1 &
```

停掉：

```bash
pkill -f "python3 app.py"
```

## 怎么用

1. **输入源**：选「无输入」由工具自己生成音/画；或选「本地上传」选一个音视频文件（可设重复次数，按整段循环拼接）。
2. **目标类型**：视频或音频。
3. **规格**：视频可选分辨率、封装（`.mp4` / `.mov`）、横竖屏、时长；音频可选 MP3 / AAC / FLAC / m4a / wav 和时长。
4. 点「生成测试文件」，完成后点下载。

生成文件在项目目录 `generated/` 下，大约 **30 分钟**后自动删除，请及时下载。

## 内置测试素材

`samples/` 目录随项目一起管理和部署。在页面选择「无输入」后，可从分类菜单中选择对应语料；未选择内置素材且未上传文件时，默认使用 `samples/单人声多人声/单人.m4a`。当目标时长超过素材时，会循环素材并截断到目标时长。

部署到其他机器时，请完整保留 `samples/` 目录。当前素材总量约 3.8 MB，适合直接提交到 Git，不需要 Git LFS。
